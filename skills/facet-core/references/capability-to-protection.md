# From Capability to Protection

Run this when the promise is about protection, safety, or a priority, and the company offers a feature as the evidence. A feature that exists is not a protection that happens. These checks find where the distance is.

## Checks

| Check | Question | Where the evidence is |
|---|---|---|
| Discoverability | How many steps from the default screen to the control? Is the stronger version off the default path? | The company's own help pages, which publish the click path |
| Setup burden | Does the effect require another person, an extra account, or a linking step? | Help pages for parental or admin controls |
| Default strength | If the user does nothing, what is on, and how strong is it? | Product announcements, help pages |
| Dismissal cost | How does someone get past the guard, and who holds the key? | Help pages describing the passcode, snooze, or skip |
| Reversibility | Can the protected person switch the protection off? | Help pages describing how to turn the setting off |
| Coverage | Which devices, markets, ages, and products does it apply to? | Help pages, regional announcements |
| Measured outcome | Is there evidence that behavior changed? | Regulators, independent research, published telemetry |

## Reporting

- Keep only the checks that produced evidence. Two to four in the answer.
- Order them the way a user meets them, not by severity.
- Each one gets a short bold heading and one or two plain sentences.
- Drop a check that found nothing. Never fill it with an assumption.

## Using numbers

Uptake and awareness numbers are the strongest evidence here and the easiest to invent. Do not estimate one.

When the company's own number is not public, a published number for the same kind of feature can carry the point, as long as the answer says whose number it is. `Family Pairing activation was 4-5% of UK teen monthly users in February 2024, per Ofcom` is evidence. `Family Pairing is rarely used` is not.

A number found through search coverage rather than the source document is still usable. Record where it was read and that the primary was not opened.
